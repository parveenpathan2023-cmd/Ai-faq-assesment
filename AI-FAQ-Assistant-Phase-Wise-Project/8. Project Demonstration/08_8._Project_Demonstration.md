# Phase 8 – Project Demonstration

## Demonstration Objective
Show the complete API workflow from registration to FAQ management and Gemini-powered AI functionality.

## Demo Sequence

### Step 1 – Install Dependencies
```bash
npm install
```

### Step 2 – Configure Environment
Create `.env`:
```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/ai_faq_assistant
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_google_gemini_api_key_here
```

### Step 3 – Start Server
```bash
npm start
```

### Step 4 – Health Check
```text
GET /
```

### Step 5 – Register
```text
POST /api/auth/register
```

Example:
```json
{
  "name": "Demo User",
  "email": "demo@example.com",
  "password": "password123"
}
```

### Step 6 – Login
```text
POST /api/auth/login
```
Copy the returned JWT.

### Step 7 – View Profile
```text
GET /api/auth/profile
Authorization: Bearer <token>
```

### Step 8 – Create FAQ
```text
POST /api/faqs
Authorization: Bearer <token>
```

Example:
```json
{
  "question": "What is Node.js?",
  "answer": "Node.js is a JavaScript runtime used for server-side applications.",
  "category": "Technology"
}
```

### Step 9 – Search FAQ
```text
GET /api/faqs/search?q=Node
```

### Step 10 – Generate AI Answer
```text
POST /api/ai/answer
Authorization: Bearer <token>
```

Example:
```json
{
  "question": "What is artificial intelligence?"
}
```

### Step 11 – Generate AI FAQ
```text
POST /api/ai/generate-faq
Authorization: Bearer <token>
```

Example:
```json
{
  "topic": "Machine Learning"
}
```

### Step 12 – Update/Delete FAQ
Demonstrate that the creator can update or delete their FAQ.
