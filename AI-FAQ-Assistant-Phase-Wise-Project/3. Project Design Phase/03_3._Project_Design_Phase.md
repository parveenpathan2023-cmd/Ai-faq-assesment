# Phase 3 – Project Design Phase

## Architecture

```text
Client / Postman
       |
       v
   Express API
       |
   Middleware
       |
 +-----+----------------------+
 |            |               |
Auth       FAQ Routes       AI Routes
 |            |               |
Controllers Controllers    Controller
 |            |               |
User Model  FAQ Model    Gemini Service
 |            |               |
 +------------+---------------+
              |
           MongoDB
```

## Layered Design

### Routes
Defines API endpoints and attaches middleware.

### Controllers
Contains business logic for authentication, FAQ management and AI operations.

### Middleware
- Authentication
- Request validation
- Centralized error handling

### Models
- User
- FAQ

### Services
`geminiService.js` isolates Gemini API communication from controllers.

## Database Design

### User
```text
User
├── name
├── email
├── password
├── createdAt
└── updatedAt
```

### FAQ
```text
FAQ
├── question
├── answer
├── category
├── createdBy → User
├── createdAt
└── updatedAt
```

## Security Design
1. Passwords are hashed with bcrypt.
2. JWT is issued after successful authentication.
3. Protected routes use authentication middleware.
4. FAQ update/delete operations verify ownership.
5. AI endpoints are protected to reduce API abuse.

## AI Design

### AI Answer
Question → Gemini → concise direct answer

### AI FAQ
Topic → Gemini → structured JSON containing:
- question
- answer

The AI FAQ endpoint uses a response schema to encourage predictable JSON output.
