## Development Flow

### 1. Start Project
```bash
npm install
```

### 2. Configure `.env`
Set MongoDB URI, JWT secret and Gemini API key.

### 3. Start Server
```bash
npm start
```

### 4. Test API
Use Postman collection:
`AI_FAQ_Assistant_API.postman_collection.json`

## Main API Flows

### Registration
Client → validation → controller → User model → password hashing → MongoDB → JWT response

### FAQ Creation
Client → JWT middleware → validation → FAQ controller → MongoDB

### FAQ Search
Client → search query → MongoDB regex search → matching FAQs

### AI Answer
Client → JWT middleware → validation → AI controller → Gemini service → answer

### AI FAQ
Client → JWT middleware → validation → AI controller → Gemini structured response → question/answer JSON
