1. Postman API testing
2. Automated integration testing through `test_api.js`

## Integration Test
Run:
```bash
node test_api.js
```

The test script checks:
- Database connection
- Health endpoint
- Registration
- Duplicate registration prevention
- Login
- Protected profile
- FAQ creation and retrieval
- Search
- Ownership/security behaviour
- AI endpoint behaviour where configured

## Security Testing
- Missing JWT
- Invalid JWT
- Cross-user FAQ modification
- Cross-user FAQ deletion
- Invalid ObjectId
- Invalid input values

## Expected Outcome
All core API operations should return the documented status codes and JSON structures.
